# 公開前セキュリティ点検

点検日: 2026-10-23。公開用コピーのみを対象とし、開発環境・常駐環境・個人データは変更していません。

## 検査方法

公開予定の全ファイルを対象に、認証情報形式、秘密鍵ヘッダ、メール形式、ユーザー固有パス、長いサービスID、私有サービスURLを機械検索しました。元環境の機密設定値についても値を表示せず一致比較しました。検出箇所を分類し、設定・テスト・fixture・HTML/CSSと追加画面例を確認しています。Git内部は到達可能履歴、reflog、全ローカルオブジェクトを調査しました。

## 結果

- 実際のトークン・APIキー・秘密鍵・ローカル固有の接続設定に該当する文字列は、公開対象内では検出していません。
- 公開用の `.env.example` はゼロから作り直し、秘密値・実IDを含めていません。通常の `.env` / `.env.local` は除外しています。
- メール形式の検出はexample系ドメインの異常系テストです。認証情報風のダミー値は、マスキング動作を検証するための合成文字列です。
- Discord / Notion URLはコード内のURL組立てと架空の小さなIDのテストです。個人環境のURLを記載した運用引き継ぎ資料はコピーしていません。
- 個人ハンドルに見えるテスト値を架空のプレイヤー名・ユーザー名へ置換しました。
- `tests/fixtures/` は7件の例示JSONです。URL・メール・実サービスID・認証情報の既知パターンを検出していません。添付のBase64は1×1 PNGです。
- 画面例は専用デモの架空メモ3件のみを表示した画像です。ブラウザで本文3件を照合し、目視確認しています。

## 既存Gitの扱い

元リポジトリは到達可能コミット0件、追跡ファイル0件、reflog 0件でした。ただし内部には542 blob / 120 treeのオブジェクトがあり、うち3 blobにローカルの機密設定値と一致する文字列がありました。これは外部流出を確認したという意味ではありません。既存 `.git` とその全オブジェクトを公開用コピーへ持ち込まず、新規のGitリポジトリを作成しました。元オブジェクトの削除・履歴書換えはしていません。

## 除外対象

元の `.git`、`.env*`（新規テンプレートを除く）、個人SQLite / 添付 / バックアップ、logs、認証セッション、キャッシュ、仮想環境、ビルド生成物、egg-info、個人環境の引き継ぎ資料、クラウド配備スクリプトを除外しました。macOSの汎用スクリプトとplistテンプレートだけはテストに必要なため含め、説明資料の個人パス・既存運用状況を除いています。

`.gitignore` にはDB、バックアップZIP、秘密鍵、サービスアカウントJSON、ブラウザstorage state等を追加しています。実際の公開ファイル一覧は `PUBLIC_FILES.txt` です。

## 限界と公開直前の再確認

パターン検査と対象箇所のレビューであり、未知の形式の秘密値や全コードの第三者由来を保証する監査ではありません。この点検を終えた時点では、GitHubのPrivate作成・push・Public切替は未実施でした。以降の登録状況はGitHubの設定を参照してください。ファイル追加・変更後は再点検が必要です。外部サイト連携の利用条件と実データの本番運用は今回の点検とは別です。
