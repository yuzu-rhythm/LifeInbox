# 実装と確認範囲

2026-10-23の公開用スナップショット。

| 項目 | コード上の状態 | 今回の確認範囲 |
| --- | --- | --- |
| 入力・分類・原文保存 | 実装あり | Mock / 一時SQLiteのテスト |
| 支出・食事・メモ・タスク等 | 実装あり | テスト。画面例は架空のメモのみ |
| FastAPI Web画面 | 実装あり | TestClient、架空データのローカル画面 |
| バックアップ・出力 | 実装あり | 一時データによるテスト |
| Discord / OpenAI / Notion | 接続処理あり | Mockのみ。実アカウントへの送信・同期は未実施 |
| 音ゲー収集・画像生成 | 収集器・描画・状態管理あり | fixture / Mockテスト。実サイト認証や利用条件適合は未確認 |
| iPhone / Health等のAPI | API・モデルあり | Python側テスト。実端末連携は未確認 |
| Cloud Run / クラウドIngress | エントリポイント・Dockerfileあり | コードのテストのみ。ビルド・配備・クラウド側認証は未確認 |
| Google Classroom | 将来連携として記載されていたもの | 実サービス取得機能は未実装 |
| Notionからの逆同期 | 対象外 | 一方向アーカイブのみ |
| 外部SNSへの直接投稿 | 未実装 | 下書きのローカル管理のみ |

本リポジトリは開発経験を説明する資料であり、個人の既存データや本番用認証情報を含みません。ユーザー数、業務効率の改善率、外部公開サービスの稼働実績など、測定していない成果は記載していません。
